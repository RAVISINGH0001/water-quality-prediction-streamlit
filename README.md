# 💧 Water Quality Prediction App (ML + Streamlit)

An end-to-end Machine Learning application that predicts whether water is **Safe (Potable)** or **Not Safe**, using chemical parameters such as **pH, Hardness, Solids, Turbidity, and Trihalomethanes**.

## 🚀 Key Features
- Data preprocessing + ML model prediction
- Streamlit web app for real-time input & prediction
- **Rule-based Health Risk Detection** (LOW / MEDIUM / HIGH)
- **Final Decision = ML + Safety Rules**
- Downloadable Water Quality Report

## 🧠 Tech Stack
Python | NumPy | Scikit-learn | XGBoost | Streamlit
